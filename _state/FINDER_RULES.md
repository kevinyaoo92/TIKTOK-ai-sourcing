# 找货规则（稳定版）

冻结时间戳: 20261001_114414
状态: 已验证可用

## 卡片层（不打开详情）

1. 商家类型筛选: 硬编码图片签名匹配（SHOP_IMG_SIGS）
2. 卡片层性别过滤: _title_matches_keyword 剔除标题不合的商品
3. AI 语义剔除: 只剔除"明显错的"，保留全部其余，不排序，不截断
4. 按店铺回头率降序排列

## 详情层（打开详情）

逐条判定，任一不通过立即 pass：

1. 回头率 > 档位阈值（60/50/40/30）
2. 24h 揽收率 > 档位阈值（60/40/20/0），若为 None 不拦截
3. SKU 每个维度 <= 8
4. 库存 min >= 档位阈值（严格/中等: 2000, 宽松/最宽: 1000）
5. MOQ = 1
6. 性别一致性 _title_matches_keyword

不做: 保证金检查。

## 库存与 SKU 数据来源

- SKU 维度: window.context.result.data.Root.fields.dataJson.skuModel.skuProps
- 全组合库存: skuModel.skuInfoMap[*].canBookCount
- 兜底: skuInfoMap 找不到时回退 DOM 抓取

## 流程

第1页整页遍历
  命中 >=1 -> 输出（最多3个）
  0命中 -> 翻第2页整页遍历
    命中 >=1 -> 输出
    0命中 -> 降级下一档
严格 -> 中等 -> 宽松 -> 最宽
命中 3 个即停
结果不排序，按找到顺序返回

## 档位定义

| 档位 | 回头率 | 24h 揽收 | 库存 |
|---|---|---|---|
| 严格 | >60 | >60 | >=2000 |
| 中等 | >50 | >40 | >=2000 |
| 宽松 | >40 | >20 | >=1000 |
| 最宽 | >30 | >0  | >=1000 |

SKU 阈值: 每维 <=8（所有档位一致，不降级）

## 关键教训

1. 改 .py 后必须重启后端
2. AI 只剔除不排序，保留全量候选池
3. 规则执行不能擅自改动：整页遍历、翻页、降级、命中 3 个停
4. 回退备份要确认版本内容
5. 搜索池错的类目，AI 无法纠正，只能从搜索 URL 层面用 featurePair 限类目
