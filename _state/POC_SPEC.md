## 关键锚点

- POC 唯一目标：用户 Chrome + 1688 登录态 → 扩展执行找货 → 最多 3 个货源返回
- 四阶段验收：POC-1 通信 / POC-2 搜索页 / POC-3 详情页 / POC-4 完整闭环
- 第一原则：扩展不保存 1688 账号密码；不保存 DeepSeek Key；服务器不远程控制浏览器
- 四档规则由后端下发，扩展只执行
- AI 只做 keep/reject，不排序、不打分、不选 final 3
- 失败原因必须可查（日志）

## 四档阈值

| 档位 | 回头率 | 24h揽收 | 库存 |
|---|---|---|---|
| 严格 | >60 | >60 | ≥2000 |
| 中等 | >50 | >40 | ≥2000 |
| 宽松 | >40 | >20 | ≥1000 |
| 最宽 | >30 | >0  | ≥1000 |

SKU 每维 ≤8（所有档位）。
MOQ = 1。
24h 揽收 None 不拦截。
保证金不检查。

## 搜索流程

每档最多查第 1、2 页。第 1 页无命中 → 第 2 页。两页都无 → 降级下一档。
严格 → 中等 → 宽松 → 最宽。命中 3 个立即停止。不无限翻页。

## SKU/库存数据来源

- SKU 维度：`window.context.result.data.Root.fields.dataJson.skuModel.skuProps`
- 全组合库存：`skuModel.skuInfoMap[*].canBookCount`（取最小）
- 兜底：DOM 抓取
- 记录 `inventory_source: skuInfoMap / dom`
