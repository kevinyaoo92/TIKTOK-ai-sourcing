# Frontharbor 找货助手 — 安装与使用

## 一、安装（仅需一次）

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车
2. 右上角打开「开发者模式」开关
3. 点左上角「加载已解压的扩展程序」
4. 选择本目录（`frontharbor-extension` 文件夹）
5. 扩展卡片出现「Frontharbor 找货助手」，安装完成

## 二、使用

1. 保持 Chrome 已登录 1688（`www.1688.com` 右上角能看到你的账号名）
2. 打开 Frontharbor 网站（`http://118.89.85.175`，需要 Basic Auth 密码）
3. 进入商品机会详情
4. 点击「找优质货源」
5. 弹窗中点「立即找货」
6. 等待 1~3 分钟（扩展会自动打开/关闭 1688 页面）
7. 弹窗显示 1~3 个货源

## 三、常见问题

**Q：点「立即找货」后等 60 秒没反应？**
A：检查扩展开关是否打开（`chrome://extensions/`），或 1688 登录态是否过期。

**Q：找货结果为空？**
A：当前商品机会没有匹配到符合质量标准的货源，可以换一个机会试。

**Q：扩展图标灰色/不工作？**
A：在 `chrome://extensions/` 中重新加载一次扩展。

## 四、注意事项

- 扩展使用你自己的 1688 登录态，不保存账号密码
- 每次找货会消耗一次免费体验额度
- 如遇异常，截图反馈给 Frontharbor 团队
